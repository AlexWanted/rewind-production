     - Verify media loads (check Network tab: responses from /api/uploads/...)
     - Verify Content-Type headers correct (image/jpeg, video/mp4, etc.)
  3. Test FTP fallback:
     - Stop FTP server (or block FTP port)
     - Refresh portfolio page
     - Verify media still loads from local public/uploads/
     - Check Network tab: responses still 200 OK
  4. Test file listing:
     - Visit admin panel file manager
     - Verify file list loads from FTP
     - Stop FTP server, refresh admin panel
     - Verify file list falls back to local
  5. Test no upload regression:
     - In admin panel, upload a new image
     - Verify upload succeeds (returns FTP public URL)
     - Verify new file appears in FTP listing
     - Verify new file accessible via /api/uploads/...
  6. Test path traversal protection:
     - Try /api/uploads/../../../etc/passwd → should return 400/404
     - Try /api/uploads/..%2F..%2Fetc%2Fpasswd → should return 400/404
  7. Verify Cache-Control headers present on media responses
